# Applications of Information & Communication Technologies 
## Course Overview
This course introduces fundamental concepts of computer technologies, focusing on basic understanding of computer, practical usage and real-world applications.

## 🎯Learning Outcomes
Students will be able to:
- Understand basic computer concepts
- Identify hardware and software
- Perform basic computer operations
- Use office tools effectively
- Understand internet usage and safety

## Course Modules
- Introduction to Computer Systems
- History of Computers
- Computer Organization
- Hardware & Software
- Operating Systems Basics
- Word Processing
- Spreadsheets
- Presentations
- Intro to Transmission Media
- Internet & Network
- Digital Safety
- Emerging Technologies

## Pracrical Work
Hands-on sessions covering:
- File management
- MS Word
- Excel basics
- PowerPoint
- Internet & Email
